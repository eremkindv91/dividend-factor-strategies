# UX-PROBLEMS — 10 главных проблем (Итерация 1, §8.2)

Формат: симптом → причина в коде → решение → риск. Ранжировано по влиянию на «понять за 10–20 сек».

| # | Симптом | Причина в коде | Решение | Риск |
|---|---|---|---|---|
| 1 | Точка входа — «Новости», а не состояние рынка | порядок `.section-tab` в `index.html`; hash по умолчанию | «Обзор» на базе `market` первым; новости — блоком на Обзор + второй уровень (§9, §11) | средний — роутинг/алиас `overview→market` |
| 2 | 9 разделов выглядят равнозначными | плоские горизонтальные табы | sidebar с группировкой основные/дополнительные (§9) | высокий — новый shell вокруг рабочих секций |
| 3 | Числа без контекста (горизонт/база/надёжность) | форматтеры `ru/PU` без слотов метаданных | `.metric-card` со слотами значение·горизонт·база·n·дата·метод (§17, §5) | низкий — подача, не расчёт |
| 4 | «Ложная точность» пугает/вводит в заблуждение | Sharpe/beta 2 знака без интервала | интервалы+надёжность (§5.2) | низкий |
| 5 | Пять «Загрузка…» подряд на Обзоре | последовательные `innerHTML='Загрузка'` в `render*` | skeleton с геометрией блока (§11, §20) | низкий |
| 6 | Длинные `section-intro` съедают первый экран | `<p class="section-intro">` почти в каждой секции | в tooltip/«Как рассчитано»/методологию; badge «Не ИИР» оставить (§10) | низкий |
| 7 | Портфель начинается с тех-описания формата | `mp-editor` подсказка `ticker;qty;avg` сверху | пустое состояние с поиском/кол-вом/ценой; формат — в advanced (§12) | средний — не тронуть парсер/ключ |
| 8 | Мобильная навигация = горизонтальный скролл табов | `.section-tabs` overflow-x | нижняя bottom-nav (Обзор/Портфель/Акции/Стратегии/Ещё) (§9) | средний |
| 9 | Облигации: YTM без ловушек рынка РФ | нет полей оферта/флоатер/аморт | маркеры «не проверено» + «Ограничения» (§5.6) | низкий — только подача |
| 10 | Дивпоток: неясно gross/net/prob | 3 разных числа в разных местах | единый переключатель Gross/Net/Prob (§5.5) | низкий |

**Не-проблемы (сделано верно, не трогать):** разведение дневного/месячного риска, `DR_EXCL`+confidence,
MCFTR как total-return бенчмарк, honest-«н/д» вместо оценок, P/E-гейт качества.
