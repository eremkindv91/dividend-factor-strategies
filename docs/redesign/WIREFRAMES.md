# WIREFRAMES — текстовые каркасы (Итерация 1, §8.6)

Каркасы ключевых экранов. Реализация — Итерации 2, 4, 5, 6. Расчётные значения — из существующих
глобалов (`PFX_STATE`, `VIEW`, `DATA`, `MARKET_PE` …), не переписываются.

## Обзор (app-shell: sidebar | topbar | content)

```
┌ topbar: «Обзор» · дата данных · [fresh/stale/fallback] · [Не ИИР] · CTA «Собрать портфель»
├ KPI-ряд (4–6): IMOEX/MCFTR ↕ | режим рынка | ключ.ставка/RFR | P/E рынка* | ближ. событие
│   *P/E — «на проверке качества данных» (гейт активен)
├ [Рыночный режим — крупно]              │ [Сегодня и ближайшие события]
│  человеческий вывод, шкала −13/+17,     │  дивотсечки · ЦБ · отчётности
│  что изменилось, «Как определяется»     │  компактная таймлиния
└ Level2 (details): график рынка · сигналы · настроение · фаза подробно
```

## Портфель — пустое

```
┌ «Добавьте портфель для анализа»
├ [поиск бумаги] [кол-во] [ср. цена] [Добавить]   [Импорт CSV] [Заполнить пример]
├ «Расчёт локальный в браузере — файл никуда не отправляется. Не ИИР»
└ ▸ advanced: ручной ввод списком (формат ticker;qty;avg)
```

## Портфель — заполненное

```
┌ Дашборд KPI: Стоимость | Результат | Доходность | Риск(VaR 95%,1мес) | Дивпоток[Gross▾] | Позиций | Концентрация | Статус
│   у каждого числа: горизонт · база · n=91мес · метод · дата
├ «Что требует внимания»: [концентрация SBER 56% > 15%] [PCR …] [cut_risk …] [β 1.17] …
│   каждый alert: что · насколько (число+порог) · какие позиции · →разбор
├ Вкладки: Резюме · Состав · Доходность · Риск · Дивиденды · Сценарии · Memo
└ ▸ «Данные и ограничения»: исключено SNGS (no_data) · n=91мес · месячная база · дата снапшота
```

## Акции

```
┌ [поиск debounce250] · чипы (высокий рейтинг/надёжный див/недооценён/выс.дивдох/низкий риск/полные данные/сектор) · «найдено N» · [Таблица|Карточки|Карта]
├ карточка: тикер·название | цена ↕ | рейтинг | дивдох(gross/net) | вероятн.выплаты(1−cut_risk) | риск | сектор | свежесть | sparkline | вердикт
└ →клик: drawer/dialog: Обзор·Дивиденды·Финансы·Рейтинг·SHAP(объяснение модели,не прогноз)·График·Источники
```

## Карточка инструмента (drawer)

```
┌ тикер · название · цена ↕ · [свежесть]
├ График цена+объём (MOEX ISS, уже реализован) · периоды 6М/1Г/3Г/Макс
├ вердикт · дивметрики(gross/net) · оценка(DCF/DDM) · сектор-перцентили
└ SHAP (объяснение модели) · источники
```

## Стратегии

```
┌ карточки: RU Quality | Momentum | Див.переоценка | Min Variance | Max Sharpe | Risk Parity | Inverse Vol
│   на карточке: описание · цель · риск · горизонт · N бумаг · статус данных · [Настроить]
│   marlamov: подпись «лагированный Top-10 baseline» — видимая пользователю
└ конструктор (шаги): стратегия → размер → ограничения → взвешивание → предпросмотр → итог
```
