## 🟠 Средний риск

- **Импорт CSV** — парсер `pfxParseValidate` (запятая-десятичная, `#`-комменты, дубли, алиасы). Тест после правок Портфеля.
- **Ленивая загрузка тяжёлых разделов** (cbr 484 КБ, market_history 480 КБ) — не сломать существующий lazy, не грузить на старте.
- **`loadJSON`-обёртка (§6.1)** — перевод 27 `fetch` на версионирование; оставить `no-store` только для live ISS-котировки. Ошибка → рассинхрон данных.
- **Скрытые секции** (`hidden`) — не запускать таймеры/ресайз графиков в скрытых (§6.3).

## 🟡 Низкий риск

- Подписи метрик (§5), skeleton, токены, типографика — подача, не расчёт; baseline не двигают.
- `aria-live` сузить до строки статуса — проверить, что рендер не ломается.

## Известная нестабильность (не регресс, а находка)

Месячный `PFX_STATE.boot` не seed-детерминирован → в baseline вынесен в `stochastic_not_compared`.
При сидировании (согласованное изменение расчёта) — сначала обновить baseline осознанно, не молча.
