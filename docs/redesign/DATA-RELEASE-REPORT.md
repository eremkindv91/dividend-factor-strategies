# Выпуск: автоматическое обновление и все доступные показатели

Дата: 22 ноября 2026 года. Сайт: https://eremkindv91.github.io/dividend-factor-strategies/#stocks.

## Что изменено

- Восстановлены обновление котировок и ежемесячный пересчёт модели: устранены
  блокирующая установка необязательного SDK и несовместимость pandas StringDtype.
- Финансовый workflow получает pypdf и scikit-learn; тесты запускаются до сетевого
  обхода источников. Проверка размера облигационной выборки сопоставляет результат
  с журналом загрузки, а не требует ровно максимальное число выпусков.
- Data Foundry обновляется ежедневно в 07:17 МСК; новые данные публикуются без чата.
  SQLite проверяется по размеру и SHA-256, источники и версия сохраняются.
- Импорт больше не ограничен выручкой, чистой прибылью, RUB или консолидированной
  МСФО: включены все доступные проверенные метрики, отдельная отчётность, другие
  валюты и результаты с проверенной формулой. Стандарты и периметры не смешиваются.
- Панель открывается с выбранным режимом «Все показатели». Можно выбрать отдельный
  показатель и переключить последние наблюдения на историю. В карточке выводятся
  все доступные последние наблюдения, а не пять заранее выбранных строк.
- Проценты, суммы, значения на акцию и мультипликаторы имеют собственные единицы.
  Расчётные показатели отмечены; формулы и сохранённые входы доступны в источниках.
- История разделена по компаниям, чтобы не загружать всю базу в браузер и не
  превышать лимит файлов GitHub. Первым загружается индекс; подробности — по запросу.
- В скринере есть общее покрытие и статус Data Foundry каждой бумаги. Возраст цены
  и модели вычисляется на клиенте. Основной JSON загружается после build manifest
  с обязательной проверкой сети, чтобы старый кэш не выдавался за свежий срез.
- Мобильные фильтры, даты и объяснение рейтинга свёрнуты; поиск остаётся доступен.

## Границы выпуска

Пропуски не заполнены искусственными значениями. Отсутствие значения у поставщика
не означает ноль или отсутствие отчёта эмитента. Data Foundry обновляется вручную;
сайт автоматически забирает опубликованные версии, но не ускоряет работу поставщика.

Фундаментальный слой Data Foundry и модельные прогнозы имеют разное происхождение.
Этот выпуск не подменяет незаметно входы действующей ML/DCF-модели. Эмитентное
сопоставление классов акций, полный PIT-аудит и проверки F1–F6 остаются отдельными
задачами спецификации. Утверждать, что все 269 бумаг имеют полный и заново сверенный
набор финансовых показателей, нельзя.
