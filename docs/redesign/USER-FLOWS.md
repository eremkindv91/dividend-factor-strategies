# USER-FLOWS — сценарии (Итерация 1, §8.4)

Три роли. Для каждой — цель, текущий путь (по коду), целевой путь, метрика успеха (§26).

## A. Новый пользователь (первый визит)

- **Цель:** понять, что это за продукт, что с рынком, куда добавить портфель, где искать акции.
- **Сейчас:** открывается «Новости»; фаза рынка/портфель — на других вкладках; нет единой точки входа.
- **Целевой:** «Обзор» первым экраном — KPI (IMOEX/MCFTR, режим, ставка, P/E, ближайшее событие),
  карточка режима рынка, лента событий, CTA «Собрать портфель»/«Найти акцию».
- **Успех (§26.A):** на 1440×1000 и 390×844 выше сгиба видно: что за продукт · состояние рынка ·
  где добавить портфель · где акции.

## B. Владелец портфеля (возвращается)

- **Цель:** состояние портфеля, главные риски, что требует внимания, ближайшие дивсобытия.
- **Сейчас:** вкладка «Портфель», ввод `ticker;qty;avg`, расчёт локально (`pfxCompute`→`PFX_STATE`);
  X-Ray с VaR/CVaR/alpha/beta/риск-бюджет/дивстресс/bootstrap/ребаланс/memo. Восстановление из
  localStorage `myPortfolio.v1`.
- **Целевой:** дашборд-резюме (стоимость·результат·риск·дивпоток с gross/net/prob·концентрация·статус)
  + «Что требует внимания» (концентрация ≥15%, PCR, cut_risk, beta, VaR, сектор, effN, спред к RFR) с
  переходом к разбору. Маркеры надёжности/горизонта/налога у каждого числа.
- **Успех (§26.B):** выше сгиба заполненного портфеля читается: состояние · риски · позиции внимания ·
  ближайшие дивсобытия.

## C. Продвинутый инвестор (глубокий анализ)

- **Цель ≤ 3 клика:** подробный риск-анализ · SHAP · факторная стратегия · график инструмента ·
  методология показателя.
- **Сейчас (клики):** риск-анализ — Портфель→раскрыть details (2); SHAP — Акции→карточка→SHAP (3);
  стратегия — Стратегии→конструктор (2–3); график — Акции→карточка→график (2); методология — вкладка
  Методология (1) или tooltip.
- **Целевой:** сохранить ≤3, унести технические вводные в drawer/«Как рассчитано».
- **Успех (§26.C):** для каждой цели точная последовательность ≤3 клика.

## D. Финансовая честность (§26.D)

Для 5 чисел с экрана портфеля (напр. Sharpe, β, VaR 95%, дивпоток, CAGR) — из интерфейса, БЕЗ открытия
методологии, должно читаться: горизонт · база gross/net · частота · размер выборки (n=91 мес) · метод ·
дата данных. Сейчас частично (горизонт «(мес)» есть, n/база/метод — не у каждого числа). Дорабатывается
в Итерации 3 (§5).
