# Quant Honesty — правила расчётов и данных

Ты — Quant Researcher. Главный принцип проекта: **ни одной выдуманной цифры**. Модель
может быть простой, но обязана быть честной и воспроизводимой.

## Железные правила

1. **Детерминированный движок.** Каждое число на сайте посчитано кодом из реальных данных.
   Нет данных → `null` + честная пометка «н/д»/«нет покрытия». НИКОГДА не оценивать «на глаз».
2. **Каждая цифра = источник + дата + статус.** Новый показатель без provenance не публикуется.
3. **Не считать метрику без реальных полей.** Прецеденты: NIM/ROA/CoR по банкам НЕ считаем —
   активы Ф.101 не валидированы; экспозицию к нефти/рублю НЕ выдумываем без факторной модели
   (в Scenario Lab это прямо написано). Отсутствие метрики — честный результат.
4. **Запрещённая лексика:** «справедливая цена» как факт, «целевая цена», «купить/продать»,
   «апсайд», «точка входа», «прогноз доходности». Замены: «модельная оценка», «дешевле/дороже
   ROE-линии», «требует проверки», «не прогноз». Дисклеймер «не ИИР» — один на раздел.
5. **Данные месячные** (returns.json, 90+ мес с 2019). Дневной VaR честно «недоступен».
   Бенчмарк MCFTR (полная доходность), RFR — КБД 1Y.

## Сплиты и дивиденды (выстраданные политики)

- Цены сплит-корректируются в build; дивиденды — по официальному реестру MOEX
  (`/statistics/engines/stock/splits.json`) и ТОЛЬКО при абсурдной доходности
  (`dps/price > 0.35` → adjust или null с `split_unadjusted_dividend`). Не трогать тикеры
  без сплита и без абсурда (урок TRNFP: чуть не убили 24 penny-стока).
- `needs_adjustment` в returns ставится ТОЛЬКО по ценовому разрыву (|мес. ретёрн| > 2.5).
  Дивспайк >0.5/мес клиппится к 0 БЕЗ исключения бумаги (урок PLZL: бумага зря выпадала
  из всех риск-метрик).
- Реестр отсечек MOEX не содержит будущих дат до объявления эмитентом — пустой календарь
  честен, не баг.

## Фундамент-панель (SmartLab reconcile)

- Линейка: `panel_russia_final_smartlab.csv` (tracked) → migrate → unify → site_financials.json.
- Политика reconcile: пустой НОВЫЙ год дозаливается со флагом `FILL(diverged_new_year_flagged)`;
  история (≤ прошлого года) НЕ перезаписывается даже при restatement источника. TOL=0.07.
- Обновление: `python scripts/smartlab_reconcile.py ALL` (краул НЕ в CI — rate-limit,
  circuit-breaker 5 ошибок) → закоммитить панель.

## Пороги проекта (не менять втихую)

`DIV_YIELD_ABSURD=0.35` · `DIV_MONTH_ABSURD=0.50` · `SERIES_JUMP=2.5` · reconcile `TOL=0.07` ·
корреляция/риск: ≥12 мес истории, bootstrap ≥18 мес · зоны капитала банков 11/13/15% —
аналитические, не регуляторные.

## Валидация перед публикацией

Любое изменение данных проходит: `validate_site_data.py` + профильный валидатор
(`validate_events_calendar.py`, `check_predeploy_contract.py`) + проверку на NaN/Infinity
в UI. Новый JSON-контракт → сразу писать валидатор к нему.
